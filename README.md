# 👟 Adidas Sales Analysis – Excel

## 📌 Project Overview
This project focuses on analyzing Adidas sales data using Microsoft Excel. The workbook contains 1,200 sales records and summary tables to explore revenue, profit, product categories, regions, and sales performance.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization

## 📂 Dataset Information
The dataset contains 14 columns, including:
- Order ID
- Order Date
- Product Name
- Category
- Region
- Store Type
- Units Sold
- Unit Price
- Discount
- Revenue
- Profit
- Customer Age
- Gender
- Payment Method

## 📊 Analysis Included
- Revenue by Product Category
- Profit by Region
- Units Sold by Year
- Revenue by Payment Method

## 🎯 Project Objectives
- Analyze Adidas sales performance.
- Identify revenue and profit patterns.
- Understand product category performance.
- Explore regional sales trends.
- Support data-driven business decisions.
